# v0.3.1 — Complete public API documentation

All five crates gain public API documentation and runnable crate examples, making the existing library interfaces easier to use.

Original registry publication date (UTC): **2026-10-13**. Source tag
[`v0.3.1`](https://github.com/rustcommons/linux-abi-tools/tree/v0.3.1), commit
[`3cd97929a99280fca2f616dae63bd610a038e131`](https://github.com/rustcommons/linux-abi-tools/commit/3cd97929a99280fca2f616dae63bd610a038e131).
All five workspace packages were published at 0.3.1; all five are non-yanked as
verified on 2026-11-02. This is a crate release, not a source-only historical tag.

These notes were reconstructed on 2026-11-02 and were not part of the original
source tag or immutable registry archives. A later GitHub Release posting date is
the documentation backfill date, not the original registry publication date.

## Changes

- Public items are documented, crate overviews include examples, manifests describe docs.rs builds, and CI checks generated documentation.
- This is a documentation-only patch release: it does not add a provider mode, change ABI data, or change runtime/tool behavior.

## Upgrade

Consumers in the 0.3 series can take this patch without an API migration. Use the documentation for the actual resolved crate version. Source-mode GCC/binutils and container prerequisites from 0.3.0 still apply; documentation coverage does not remove them.

## Validation and limits

The [source comparison](https://github.com/rustcommons/linux-abi-tools/compare/v0.3.0...v0.3.1) records the documentation/examples/CI and synchronized manifest changes. Existing provider qualification remains scoped to its recorded source and tools. The historical release summary reports complete public documentation, but a separate final-tag test-run/package qualification bundle was not recovered for this backfill. No old suite was rerun or inferred from the presence of a CI workflow. Documentation does not establish new runtime compatibility.

The 2026-11-02 backfill audit independently downloaded all five version-0.3.1
archives, matched their registry checksums and clean VCS identities to the source
commit above, and inspected source/tag differences. This confirms artifact
identity/availability, not historical test execution. No Rust suite was rerun for
this documentation backfill. Distributions remain crates.io packages; no new
standalone binaries or SDK assets accompany these notes.
