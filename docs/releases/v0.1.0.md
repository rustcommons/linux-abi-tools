# v0.1.0 — ABI tools and explicit glibc providers

The first workspace release supplies glibc ABI queries, explicit link-provider descriptors, target presets, kernel simulation and static executable inspection.

Original registry publication date (UTC): **2026-10-11**. Source tag
[`v0.1.0`](https://github.com/rustcommons/linux-abi-tools/tree/v0.1.0), commit
[`f691c048fc2b55d6c7d891ac0a8a5e03db5ccb22`](https://github.com/rustcommons/linux-abi-tools/commit/f691c048fc2b55d6c7d891ac0a8a5e03db5ccb22).

## Changes

- `libc-abi-tools` supplies the `libc-abi` CLI, exact glibc 2.17–2.44 snapshots, ELF symbol evidence and link-only stubs. A target floor retains older symbol versions such as `GLIBC_2.2.5`.
- Explicit `libc-abi-provider-v1` descriptors support qualified glibc 2.17, 2.18 and 2.22 input profiles. Provider preparation is an external workflow in this version; automatic preparation arrives in 0.3.0.
- `linux-targets` resolves distribution/target floors; `kernel-abi-tools` supplies `kernel-seccomp` and `syscall-probe`; `linux-abi-scan` inspects ELF requirements. The `linux-abi-tools` library re-exports all four crates.

## Upgrade

Requires Rust/Cargo 1.90 or newer. The repository/umbrella is `linux-abi-tools`, but the root package and its CLI are `libc-abi-tools` and `libc-abi`. Install the individual CLI packages you need; the umbrella and `linux-targets` are libraries. Provider descriptors require real headers, startup/nonshared objects and separate target runtime libraries; the crates are not a runtime SDK.

## Validation and limits

The [tagged bootstrap validation record](https://github.com/rustcommons/linux-abi-tools/blob/v0.1.0/docs/VALIDATION.md) preserves named metadata tests and hosted checks at earlier source `084d2b6316a3af6ab16f3d25cdd67187e0b852c3`, including Windows/Linux, MSRV, 28 ABI snapshots and scoped 2.17 provider applications. These are their original bounded results, not a consolidated test run at the final release tag. The later 2.18/2.22 records retain their own scopes. A complete final-tag release-wide validation report was not recovered for this backfill. A static scan or modern-host seccomp/container run does not establish old-system compatibility.

The 2026-11-02 backfill audit independently downloaded all five version-0.1.0
archives, matched their registry checksums and clean VCS identities to the source
commit above, and inspected source/tag differences. This confirms artifact
identity/availability, not historical test execution. No Rust suite was rerun for
this documentation backfill. Distributions remain crates.io packages; no new
standalone binaries or SDK assets accompany these notes.
